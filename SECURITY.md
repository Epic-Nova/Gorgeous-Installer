# Security Policy

Please do **not** report vulnerabilities through public GitHub issues.

Send security reports privately to [vulnerabilities@epicnova.net](mailto:vulnerabilities@epicnova.net). Include affected versions, reproduction steps, impact, and a safe proof of concept when possible.

Avoid publishing exploit details until maintainers have had an opportunity to investigate and coordinate disclosure. Security support is evaluated for the current maintained codebase; no fixed response time is guaranteed.
